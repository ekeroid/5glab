

The benchmark setup:                                                               
                                                                                                                   
  Server: Deployed in k8s (open5gs namespace) via ConfigMap — benchmark-server.py                                  
                                                                                                                   
  Client: Runs locally — benchmark-client.py                                                                       
                                                                                                                   
  Connection: SSH tunnel (localhost:9900 → k8s service)                                                            
 
  ┌───────────────────────┬──────────────────────────────────────┐
  │         File          │               Purpose                │
  ├───────────────────────┼──────────────────────────────────────┤                                                    
  │ benchmark-server.py   │ Server code (deployed via ConfigMap) │
  ├───────────────────────┼──────────────────────────────────────┤                                                    
  │ benchmark-deploy.yaml │ Kubernetes Deployment + Service      │                                                    
  ├───────────────────────┼──────────────────────────────────────┤
  │ benchmark-client.py   │ Client (runs on your laptop)         │                         
  └───────────────────────┴──────────────────────────────────────┘
                                                            
  Available profiles:                                                                                              
                                                                                                                   
  ┌─────────────────┬──────────────────────────────┐                                                               
  │     Profile     │         Description          │        
  ├─────────────────┼──────────────────────────────┤                                                               
  │ latency-small   │ 64-byte ping/pong (pure RTT) │        
  ├─────────────────┼──────────────────────────────┤                                                               
  ├─────────────────┼──────────────────────────────┤
  │ latency-medium  │ 1KB ping/pong                │
  ├─────────────────┼──────────────────────────────┤
  │ latency-large   │ 8KB ping/pong                │
  ├─────────────────┼──────────────────────────────┤
  │ throughput-down │ Download 64KB chunks         │
  ├─────────────────┼──────────────────────────────┤
  │ throughput-up   │ Upload 64KB chunks           │
  ├─────────────────┼──────────────────────────────┤
  │ mixed           │ All three phases combined    │
  └─────────────────┴──────────────────────────────┘

  Usage:
  python3 benchmark-client.py 127.0.0.1 9900 <profile> <duration_seconds>

  Note: these results measure laptop → SSH tunnel → k8s pod latency (~5ms RTT, ~45-50 Mbps). To benchmark the actual 5G radio path, the client would need to run on the UE itself, not through the SSH tunnel. The tunnel measures the infrastructure backhaul, not the air interface.
